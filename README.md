# Basic API

First steps with **ASP.NET Core Web API** (.NET 9): a minimal API and a controller-based API with GET, POST, PUT and DELETE endpoints, plus a `requests.http` file for testing them.

## Structure

- BasicApieND/ — minimal API (`MapGet("/weatherforecast")`)
- WebApplication1/ — controller with GET / POST / PUT / DELETE
- requests.http — sample requests

## Run

```bash
dotnet run --project WebApplication1
```
